# Кэшбэк рядом

Полный контекст, продуктовые решения, план и промпты: [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). Инструкции помощнику: [AGENTS.md](AGENTS.md). История версий и безопасный возврат: [GIT_GUIDE.md](GIT_GUIDE.md).

Исходники и история: [приватный репозиторий SHAIINARK/cashback-upp](https://github.com/SHAIINARK/cashback-upp). Первая сохранённая версия отмечена меткой `baseline-skeleton`.

Первый скелет Flutter-приложения для Android и iOS. Рабочее название и идентификатор `ru.cashbackguide.balance_app` предварительные; перед публикацией их нужно согласовать.

## Что работает

- Русский интерфейс, светлая тема, четыре вкладки и отдельный экран проверки импорта.
- Выбор календарного месяца с переходом между годами.
- Пустые состояния без демонстрационных пользовательских данных.
- Модели пяти банков, карты, периода, категории и подтверждённого месячного набора.
- Рубли, бонусы Спасибо и другие баллы различаются. Исходные названия не объединяются.

Загрузка фотографий, OCR, ручное добавление, постоянное хранение, сравнение и виджеты пока не реализованы. Кнопка выбора скриншотов отключена. Репозиторий возвращает пустые коллекции; пользовательские данные не создаются и не отправляются. Сетевые разрешения отладочной Flutter-сборки нужны для инструментов разработки, а не для банковской интеграции.

## Структура

- `lib/domain` — модели и контракт доступа к данным.
- `lib/data` — пустой репозиторий, далее локальное хранилище.
- `lib/logic` — состояние выбранного месяца.
- `lib/app` — тема, локализация и навигация.
- `lib/presentation` — экраны и общие элементы интерфейса.
- `test` — календарные периоды, валидация и навигация.

## Запуск на Windows

Инструменты находятся в `D:\dev-tools`. После изменения переменных среды откройте новый терминал.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run -d RF8T1051S0V
flutter build apk --debug
```

APK: `build/app/outputs/flutter-apk/app-debug.apk`. Это отладочная сборка, не пакет для магазина. SDK и кэши располагаются на D: через ANDROID_HOME, GRADLE_USER_HOME и PUB_CACHE. Эмулятор необязателен при подключённом телефоне.

## iOS

Папка `ios` создана. Для сборки и проверки нужны macOS, Xcode и iPhone/симулятор. Затем настройка подписи и аккаунта для TestFlight/App Store. На Windows iOS не проверен. Разрешения на фотографии добавляются вместе с настоящим импортом.

## Дальнейшие этапы

1. Проверить локальное распознавание русского текста на исходных скриншотах и отдельно определение выбранных строк.
2. Реализовать ручное добавление и локальное хранение с миграциями.
3. Подключить выбор изображений, черновик импорта, подтверждение и защиту от дубликатов.
4. Добавить сравнение с учётом вида вознаграждения и известных условий.
5. Проверить на iPhone до завершения основных функций.
6. Пользовательский тест, виджеты и подготовка к публикации.

Не логировать изображения, реквизиты или распознанные персональные данные. Сохранённые наборы и черновики должны быть отдельными сущностями. До подтверждения нельзя перезаписывать пользовательские данные.
