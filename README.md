# Кэшбэк рядом

Flutter-приложение на русском для пяти банков с распознаванием скриншотов и для любого банка с ручным вводом названия. Версия **0.7.1+12 — удобное добавление банка и карты**.

Полный контекст и следующие промпты: [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). Правила разработки: [AGENTS.md](AGENTS.md). Откат версий: [GIT_GUIDE.md](GIT_GUIDE.md). Исходники: [приватный GitHub](https://github.com/SHAIINARK/cashback-upp).

## Что работает

- Русская тема, навигация, пустые состояния, три соседних месяца на главной.
- Главная: просмотр категорий по убыванию процентов, режим по карте и поиск по названию категории, банку, карте и примечанию в выбранном месяце.
- В списке на главной название категории выделено крупнее; банк и карта показаны под ним, процент — отдельно справа.
- Модели карт и категорий: точное название, процент, период, вид вознаграждения, примечания.
- Выбор до 10 скриншотов, временные приватные копии и очистка после просмотра.
- Локальный Android OCR русского/английского текста с моделями внутри APK.
- Банковский разбор, экран проверки с исходником, результатами, сменой банка и предупреждениями.
- Проверка импорта: переход к любому выбранному скриншоту, кнопки «Назад»/«Далее» при нескольких изображениях, выбор банка через поиск прямо на экране проверки.

Ручные карты и категории сохраняются на телефоне и показываются на главной для выбранного месяца. Если банк, месяц и категории распознаны однозначно, кнопка «Завершить проверку» сохраняет все скриншоты разом и возвращает на главную. Первую карту банка создавать вручную не требуется. Если карт одного банка несколько, нужно выбрать нужную. Месяц виден пользователю, год для сохранения определяется автоматически по ближайшему периоду или берётся со скриншота. При ошибке можно открыть «Исправить и сохранить»; на таком экране однозначные строки уже отмечены. Если на скриншоте есть и выбранные, и предложенные категории, приложение просит вручную отметить выбранные. Противоречащие уже сохранённым категориям данные не перезаписываются автоматически. Бонусы Спасибо не приравниваются к рублям, категории банков не объединяются.

Если банка нет в списке, его название можно ввести при добавлении карты или проверке импорта. Новое имя сохраняется и затем доступно в списке. Распознавание специфических экранов по-прежнему настроено для исходных пяти банков; для другого банка проверьте найденные категории и выбранность вручную.

При ручном добавлении карты поле банка открывает поиск с клавиатурой; можно выбрать найденный банк или добавить введённое название. Название карты необязательно: можно оставить автоматическое, выбрать «Дебетовая»/«Кредитная» или написать своё. Автоматическое «Карта 1» не показывается рядом с банком, пока карта одна.

В импорте месяц везде указан словом. Выбрать можно предыдущий, текущий или следующий месяц; старый скриншот требует проверки периода. Если явного названия банка нет, приложение предлагает банк по содержимому экрана. Перед сохранением такого результата оно просит подтвердить предполагаемый банк. Для изображения без признаков банковского кэшбэка поле банка остаётся пустым. Экран проверки открывается автоматически после выбора скриншотов.

Нажатие на плашку банка прокручивает её к верху экрана и открывает поиск с вариантами под плашкой. Список ограничивается свободным местом над клавиатурой и прокручивается, если вариантов больше. Назад, закрытие клавиатуры или касание вне списка закрывает выбор.

## Запуск на Windows

Инструменты находятся в D:\dev-tools. Нужны PUB_CACHE, GRADLE_USER_HOME, ANDROID_HOME, ANDROID_USER_HOME и JAVA_HOME, указывающие на соответствующие каталоги D:\dev-tools.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run --flavor standard -d RF8T1051S0V
flutter build apk --debug --flavor standard
```

APK: `build/app/outputs/flutter-apk/app-standard-debug.apk`. Это отладочная сборка, не пакет для магазина. Tesseract4Android загружается из JitPack при сборке; распознавание после установки не требует сети. Сетевые разрешения debug нужны инструментам Flutter.

Подготовка Android-релиза для Google Play и RuStore описана в [docs/ANDROID_RELEASE.md](docs/ANDROID_RELEASE.md). Окончательный Android ID утверждён, постоянный ключ создан. Подписанные APK и AAB собраны; перед загрузкой в магазины ещё нужны материалы, настройки консолей и закрытое тестирование.

Для проверки релиза рядом с обычной установкой: `flutter build apk --release --flavor qa`. APK `build/app/outputs/flutter-apk/app-qa-release.apk` имеет отдельный Android ID с суффиксом `.qa`. На Samsung SM-G780G эта копия прошла импорт, сохранение и холодный перезапуск; подробности в PROJECT_CONTEXT.md.

## Структура и проверка

`lib/domain` — модели и независимый контракт OCR; `lib/data` — нативный адаптер и репозиторий; `lib/logic` — контроллер импорта и отдельные банковские правила; `lib/presentation` — интерфейс; `android`/`ios` — платформенные движки. Пользовательская база не зависит от формата OCR.

[Результаты реальных измерений](docs/OCR_RESULTS.md), [оценка выбранности](docs/SELECTION_EVIDENCE.md), [исследование движков](docs/OCR_ENGINE_RESEARCH.md), [происхождение моделей](docs/ocr-models.json).

Для повторения измерений нужны пять оригиналов из раздела 6 PROJECT_CONTEXT.md и подключённый отладочный телефон:

```powershell
$env:OCR_DEVICE='RF8T1051S0V'
$env:OCR_PACKAGE='ru.cashbackguide.balance_app.qa'
flutter drive --flavor qa --dart-define=OCR_PACKAGE=ru.cashbackguide.balance_app.qa --driver=test_driver/ocr_driver.dart --target=integration_test/ocr_benchmark_test.dart -d RF8T1051S0V
flutter drive --flavor qa --dart-define=OCR_PACKAGE=ru.cashbackguide.balance_app.qa --driver=test_driver/ocr_driver.dart --target=integration_test/ocr_confirmation_e2e_test.dart -d RF8T1051S0V
```

QA-сборка имеет отдельный Android ID с суффиксом `.qa`, поэтому её установка и данные не затрагивают обычное приложение. Драйвер передаёт реальные изображения в приватные файлы QA-копии, проверяет копии и удаляет их после теста. Отчёт и снимок интерфейса сохраняются в игнорируемой `private-data`. Не добавлять их в Git. Второй автоматический тест проходит OCR → проверку → сохранение одним нажатием → повторное чтение локального набора; системный выбор в нём заменён передачей файла. На Samsung SM-G780G отдельно вручную проверен путь через системную галерею с одной категорией и её появление на главной после холодного запуска. После тестов пересобрать обычный APK с `--flavor standard`.

## iOS и следующие этапы

Создан локальный адаптер Apple Vision с проверкой доступности русского языка и разрешением на фотографии. Без macOS/Xcode сборка и запуск iOS **не проверены**.

Активный порядок: надёжность распознавания на реальных кадрах → пользовательская проверка Android → подготовка релизной Android-сборки → закрытое тестирование Google Play и RuStore → публикация в обоих магазинах. Локальный формат хранения имеет версию 2 и читает старую версию 1; при неизвестной версии файл не перезаписывается. До публикации проверить лицензии зависимостей. Сервер, регистрация, аналитика и монетизация не подключены.

Экспорт/восстановление данных и проверка iOS на Mac/iPhone временно отложены по решению пользователя. Без iOS-проверки выпуск в App Store не планируется.
