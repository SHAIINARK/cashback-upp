# Проверка первой пользовательской версии Android

16 октября 2026 года. Цель — проверить, можно ли без подсказок добавить категории и быстро найти нужную карту перед покупкой. Испытание на одном устройстве не заменяет проверку на других размерах экрана и версиях Android.

## Что уже проверено автоматически

На отдельной QA-копии приложения и настоящем скриншоте Ozon пройден путь выбора файла → локальный OCR → проверка → сохранение → повторное чтение файла. Повторный импорт того же кадра оставил одну карту, один месячный набор и прежнее число категорий. Выход из следующего импорта без сохранения не изменил данные. Тестовые файлы и результат OCR находятся вне Git и очищаются из приватной папки QA-копии после проверки. Обычное приложение пользователя тест не менял.

Проверка банка через поиск внутри импорта также прошла на устройстве. Отдельные виджет-тесты покрывают поиск на главной, одинаковые названия категорий разных банков, рубли и бонусы, три соседних месяца и маленький экран с крупным текстом.

## Что должен оценить человек

1. На установленной обычной версии без подсказок найти сохранённую категорию на главной и понять, каким банком платить.
2. Добавить один актуальный скриншот через системную галерею и дойти до проверки. Если категории и банк верны, оценить, понятна ли кнопка сохранения. Если есть ошибка, найти исправление. Сохранять тестовые данные необязательно.
3. Проверить, понятно ли, почему Т-Банк требует отметить выбранные предложения вручную, а предполагаемый банк — подтверждения.
4. Сообщить первую заминку, лишние действия и неожиданный результат. Важнее наблюдать фактическое действие пользователя, чем оценку дизайна в целом.

Пользователь самостоятельно проверил установленное обычное приложение: поиск сохранённой категории и путь от выбора актуального скриншота до экрана проверки. Сообщил: «Всё понятно», первой заминки не возникло. Сохранение этого нового скриншота в рамках проверки не требовалось и не подтверждено. До внешнего тестирования желательно проверить ещё один Android-телефон и новые скриншоты, особенно экран банка после сохранения выбора.
